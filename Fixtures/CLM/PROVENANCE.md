## `heads_weights/` (committed test fixture, not just a golden)

`CLMHeadsTests.swift`'s cosine check needs to actually load and run the real heads to compare
against `heads.json` — a golden JSON alone can't verify the Swift `CLMHead`/`CLMHeadPair` port.
Rather than copy this from the local `MLXCLM` checkout, downloaded the two files directly from
the public shipped repo, on the owner's suggestion:

```
curl -sL -o config.json "https://huggingface.co/RealityCat/CLM-v0.1-8B-MLX-8bit/resolve/main/heads/config.json"
curl -sL -o CLM_v0.1-8B.safetensors "https://huggingface.co/RealityCat/CLM-v0.1-8B-MLX-8bit/resolve/main/heads/CLM_v0.1-8B.safetensors"
```

`CLM_v0.1-8B.safetensors` sha256 `293646f3dca1900ac4038a1afcdee769ce64687c1636b7b311774b0663539523`,
75,552,356 bytes — matches §0's cited checksum and size exactly, and matches the local MLXCLM
checkout's copy byte-for-byte (same hash). This ~72 MB is now committed to the git repo — a
deliberate departure from every other `Fixtures/` subdirectory in this repo (all previously
KB-scale) — because CL-4a's own scope is specifically "the pure half: schema + heads, no
encoder", and the heads are the one weight artifact small enough to make that split
meaningfully testable without downloading the multi-GB encoder.
